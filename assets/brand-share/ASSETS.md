# Share poster assets

- `share-reference-v2.webp`: generated blank poster background based on the user-approved reference, 2026-09-21. Live names, declarations, figures, seals and calls to action are rendered separately. Raw master: designs/2026-09-21-brand-share/production/share-reference-v2-master.png. Gold outer-frame whitespace normalized by crop (13,8,981,1567).
- `ivory-paper-v2.webp`: generated seamless ivory paper material, reduced to512px WebP. Raw master retained with design assets.
- `cloud-ornament.png`, `footer-landscape.png`: static decorative fragments extracted from the user-supplied approved design. Cloud has a reconstructed gold alpha mask. Neither contains user data or controls.
- `fonts/MaShanZheng-Regular.woff2`: complete self-hosted font compressed from the upstream TTF. SIL Open Font License in `fonts/OFL-MaShanZheng.txt`. Sources: https://github.com/google/fonts/tree/main/ofl/mashanzheng and https://github.com/googlefonts/mashanzheng. Full character coverage retained for editable game names; loaded when a poster is generated.
- `sanmou-official.jpg`: official website icon retained from the prior integration.
- `ink-button-v2.webp`: navy painted-paper interior from the generated button-material master. Crop (240,200,1740,575) avoids its non-alpha checkerboard surround; 800×200 production texture. CSS owns the simple rounded geometry, thin rims and live labels.
